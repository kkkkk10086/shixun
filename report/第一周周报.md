## 二、RAG 智能检索系统开发

### 2.1 文档处理管线
- 实现任意格式文档（PDF、Word、TXT）→ MarkItDown/MinerU 转换 → Markdown → 智能分块
- 支持 asyncio 并发处理多个文件
- 集成 MinerU API 进行高质量文档解析

### 2.2 向量化存储
- TF-IDF + jieba 实现中文文本向量化（512维固定词表）
- ChromaDB 向量数据库持久化存储
- MySQL 数据库存储结构化元数据

### 2.3 五种检索模式
- **基础检索**：相似度搜索 + LLM 生成回答
- **增强检索**：Query重写 + HyDE + 多扩展查询 + 关键词过滤 + LLM重排 + 生成回答
- **ReAct Agent**：Think → search_knowledge → analyze_with_llm → Final Answer
- **Plan-and-Solve Agent**：获取文档 → DeepSeek 分析 → 输出
- **Reflection Agent**：获取文档 → 初始回答 → 反思 → 改进

### 2.4 查询增强功能
- HyDE（假设性文档）：用 LLM 生成假设性回答再检索
- Query 重写：口语化问题转检索友好形式
- 多扩展查询：一个问题从多角度改写
- 候选文档重排：DeepSeek 智能评分 + TF-IDF
- 汇总类问题自动识别，跳过过滤直接返回所有文档

### 2.5 Agent 范式实现
- ReAct：推理 → 行动 → 观察循环，使用 search_knowledge + analyze_with_llm 双工具
- Plan-and-Solve：获取所有文档 → DeepSeek 分析 → 输出回答
- Reflection：生成 → 反思评分 → 改进回答

### 2.6 兜底策略
- 所有模式统一：检索不到时获取所有文档发给 DeepSeek 分析
- 知识库无相关信息时，允许 DeepSeek 用通用知识补充回答

### 2.7 前端与后端
- FastAPI 后端 API（查询、上传、爬取、统计）
- HTML 前端界面（5种模式选择、文档上传、数据采集）

### 2.8 辅助功能
- Jinja2 提示词模板管理
- 结构化 JSON 数据输出（讯飞产品标准格式）
- 淘宝爬虫模块（内置演示数据，待升级 Playwright）
- MinerU 文档解析集成
- 异步并发处理

## 四、遇到的问题与解决方案

| 问题 | 解决方案 |
|------|----------|
| pip 安装超时（网络问题） | 使用清华源、pypi.org 源，分批安装 |
| ChromaDB 维度不匹配 | 创建固定512维 TF-IDF 词表 |
| TF-IDF 语义匹配差 | 加入 jieba 关键词加权 + 二元组特征 |
| LLM 重排太严格 | 放宽评分标准，汇总类问题跳过重排 |
| Agent 搜索不到文档 | 统一使用增强检索策略 + 兜底发给 DeepSeek |
| GitHub 推送被拒（密钥泄露） | 改用 .env 文件 + 重建 Git 历史 |
| 清华源找不到 modelscope | 改用默认 PyPI 源安装 |
| transformers 版本号不匹配 | 去掉版本限制直接安装最新版 |
| device_map 报错缺少 accelerate | 安装 accelerate 包 |
| 模型输出重复乱码 | 手动设置 Qwen2.5 的 chat template |
